# Baby's Tower of Babel
Simple Tower of Babel simulator using data structures from CMSC 123

## Running the Program

### Requirements
- Python 

### Setup Steps

1. **Clone the repo**
   ```
   git clone https://github.com/rgbsod/TowerBabel
   ```

2.  **Open Terminal**
3. **Run MachineProb.py in terminal**
    ```
    python MachineProb.py
    ```

## Limitations
- No Undo Action (stack could be used here)
- No Auto-Solver
